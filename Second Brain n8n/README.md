# n8n Second Brain

Import all three workflows, then set:

1. Your credentials on each node
2. Your Telegram user ID in **Check User Permissions**
3. Your Notion database in **Create Database Entry** (columns: Type, Tags, Source, URL, Author, Files)
4. Your `brain` label in **Remove E-Mail Label**
5. The Ingestion Workflow in the **Ingestion Workflow** nodes
